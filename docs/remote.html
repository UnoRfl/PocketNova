The remote uses Web Bluetooth. It works in Chrome on Android, and in Chrome or Edge on a computer. iPhone Safari doesn't support it. On an iPhone, open this page in the free Bluefy browser app instead.

Plug Pocket Nova into power, then connect. Your PC can stay connected as the keyboard at the same time.

Type the code

A 4-digit code is scrolling on Pocket Nova's lights. Typing it proves you're next to the device.
